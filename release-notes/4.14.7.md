Pins the iOS and Android native SDKs exactly to 4.14.7.

No Dart API changes. The native changes below run inside the existing start-verification call and return the same `VerificationResult`.

- Device signals: the device class hash now reads the installed memory instead of its exact bytes, so the same device model gives a stable value on iOS.
- Capture integrity: genuine cameras and Xcode runs are no longer reported as injected, on iOS and Android.
